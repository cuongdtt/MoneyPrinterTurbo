Provider decision sheet

OFox and WaveSpeed are ready-to-use sources in this checkout. fal has the broadest model marketplace, but needs a small provider adapter before it can produce clips through MoneyPrinterTurbo.

WaveSpeed

Built in

A direct keyword-to-video path with a configurable text-to-video model ID.

Default model
Seedance 2.0 Fast text-to-video
Flow
Submit prediction → poll result → download MP4
Controls in repo
Model, duration bounds, API-key rotation
Credential
One or more WaveSpeed API keys

Choose it for the shortest path from script keywords to clips.

fal

Adapter needed

One API surface for a broad, frequently changing catalog of text-to-video and image-to-video models.

Model selection
Endpoint ID, such as a Kling, Wan, Pika, Vidu, or Seedance route
Flow
Queued job or subscribe helper → result video URL
Required addition
Provider source, settings UI, schema profiles, polling and download logic
Credential
FAL_KEY

Choose it when catalog flexibility outweighs a small integration effort.

If you choose fal

Add a fal video source alongside the existing providers, keep FAL_KEY server-side, and begin with one model profile—its endpoint ID plus validated duration, resolution, and input fields. fal’s queue is compatible with the project’s submit → poll → download pattern; the variable part is each model’s input schema.

Complete user setup

What to enter for every feature.

Configure services in the WebUI settings panel or in your private config.toml. The app creates that file from config.example.toml on first run. Keep real credentials out of Git.

How configuration is organized

Server fields such as listen_host live at the top of config.toml. Most product choices live in [app]. A provider with its own settings uses a named section: for example [azure], [elevenlabs], or [whisper]. The WebUI writes to the same config locations.

# Minimal local starting point — put real credentials only in config.toml
[app]
llm_provider = "moonshot"
moonshot_api_key = "paste-your-LLM-key-here"
video_source = "local"       # Or "pexels" once a Pexels key is configured
subtitle_provider = "edge"   # Edge TTS timestamps; no API key needed

# Keep empty when only using localhost; set a strong value before network exposure
api_key = ""
