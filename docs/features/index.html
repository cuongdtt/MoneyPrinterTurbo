Product capabilities / repository guide

From a prompt to a publishable short video.

MoneyPrinterTurbo combines writing, voice, visuals, captions, music, and rendering into a configurable short-form video production pipeline.

01 / Create

Choose the interface that fits the job.

The same underlying pipeline is available for interactive work, repeatable automation, and agent-driven execution.

WebUI

Guided authoring, previews, settings, task history, generated-asset management, and onboarding.

CLI

A command-line entry point for local, repeatable, and scripted runs.

REST API

Queue-based creation for integrations, including complete video, audio-only, and subtitle-only jobs.

AI agent workflow

Included skill instructions let an agent install, configure, and run the workflow from a natural-language request.

02 / Script & planning

Start with an idea—or take complete control of the copy.

Multilingual scripting

  • Generate a script from a topic.
  • Supply or revise the full script yourself.
  • Set language, paragraph count, and custom prompts.

Scene direction

  • Extract visual search terms from a script.
  • Align terms to script order for scene-by-scene matching.
  • Generate social-post metadata for a selected platform.

03 / Visuals

Bring your own footage, find it, or generate it.

Material sources

  • Upload local images and video clips.
  • Search Pexels, Pixabay, and Coverr stock footage.
  • Use OpenAI-compatible image generation to create animated material.

AI video sources

  • Metaso MiniMax and Shengsuan Cloud.
  • VolcEngine Ark Seedance and WaveSpeed.
  • OFox access to compatible text-to-video models.

Editorial controls

  • Set clip duration and speed.
  • Use random or sequential concatenation.
  • Choose transitions and cover or contain fitting.

Visual continuity

  • Match materials to the script sequence.
  • Preserve source material order when needed.
  • Generate multiple output variants from one request.

04 / Sound & captions

Design the audio track and the words on screen.

Voiceover

  • Use TTS, a custom uploaded audio file, or no voiceover.
  • Preview voices and tune rate and volume.
  • Use Edge TTS, Azure, SiliconFlow, Gemini, MiMo, MiniMax, ElevenLabs, Chatterbox, Fish Audio, and compatible providers.

Captions

  • Use quick TTS timestamp timing or local faster-whisper transcription.
  • Style font, size, colors, outline, background, and position.
  • Use sentence or word-by-word display and a pop-spring animation.

Music

  • Select random or local music.
  • Generate music with Sonilo or ElevenLabs.
  • Control music and voice volumes independently.

05 / Delivery

Render for the platform, then retrieve or distribute.

Output formats

  • Landscape 16:9 at 1920×1080.
  • Portrait 9:16 at 1080×1920.
  • Square 1:1 at 1080×1080.

Artifact handling

  • Stream or download completed task files.
  • Review task history and restore prior settings.
  • Safely delete completed task output.

Optional publishing

  • Cross-post to TikTok, Instagram, YouTube, and Facebook Reels.
  • Publishing occurs only when the integration and platform credentials are configured.

Operational model

Asynchronous tasks with recoverable, inspectable output.

API surface

Core paths include /api/v1/videos, /api/v1/audio, /api/v1/subtitle, task lookup, material and music upload/listing, streaming/download, and LLM utilities for scripts, terms, and social metadata.

When app.api_key is configured, the API is authenticated.

Task lifecycle

Jobs run through a task manager that persists progress, results, and structured failure information. In-memory and Redis-backed managers support local use and queued deployment patterns.

Setup & keys

What you need to enter for each feature.

Use the WebUI settings panel for guided entry, or make the same changes in a private config.toml. The application creates this file from config.example.toml on first run. Never commit config.toml or share its keys.

Configuration rule of thumb

Top-level fields control the server. Most product settings live under [app]. Credentials for a specific voice provider live in its named section, such as [azure] or [elevenlabs]. The WebUI stores values in these same locations.

Minimum local configuration

For a first video without paid media services, choose a script model, use local material or add stock-footage access, keep Edge TTS, and select the desired video settings in the WebUI.

# config.toml — real key stays private
[app]
llm_provider = "moonshot"
moonshot_api_key = "paste-your-LLM-key-here"
video_source = "local"       # Or "pexels" after adding a Pexels key
subtitle_provider = "edge"   # No key required

# Server remains local-only by default
api_key = ""

API and deployment inputs

Protect a network-facing API

Keep listen_host = "127.0.0.1" for local-only use. If you expose the service beyond your machine, set a strong [app] api_key and send it from clients in the x-api-key header. Configure endpoint only when generated links need an external public base URL.

Scale task handling

For a single machine, keep enable_redis = false. For shared task state, enter private Redis details: enable_redis, redis_host, redis_port, redis_db, and redis_password. Adjust max_concurrent_tasks and max_queued_tasks to match available hardware.
