Recommended setup

For most users, keep responsibilities separate: an LLM writes text, a voice provider reads it, and a material provider supplies visuals.

Best general-purpose profile

OpenAI + fal.ai + Edge TTS

Use OpenAI for script and keyword generation, fal.ai for generated video clips, and Edge TTS for narration. This gives a clear, independent key for each service.

Defaults: portrait 9:16, random concatenation, fill/crop, 5-second clips, 1 video, subtitles enabled.

Low-cost profile

Local/Ollama + stock video + Edge TTS

Use a local LLM and Pexels/Pixabay/Coverr. This avoids paid AI video submissions and is a good first test of the full pipeline.

Trade-off: stock footage may be less literal than generated clips.

Important: a ChatGPT subscription is not an API key. OpenAI API usage is configured and billed separately. fal.ai video generation is also billed per submitted clip; the WebUI asks for confirmation before running it.

Video Script Settings

These settings determine what the narrator says and which keywords are passed to material search or AI video generation.

Video Subject

The topic or angle of the video. It is the starting input for automatic script generation.

Use a specific subject, audience, and promise for better results: “Three ways freelancers can automate invoices” is stronger than “AI”.

Script Language

Requests the language used by the generated script. Auto Detect follows the subject when possible.

Keep the subject, script, and voice language aligned to avoid awkward narration.

Video Script

Optional manual override. If filled, it is used instead of generating a new script from the subject.

Use complete punctuation; punctuation helps subtitle segmentation.

Video Keywords

Optional comma-separated visual terms. If empty, the selected LLM derives them from the script.

Manual keywords are useful when you need brand-safe, literal visuals.

Script Generation Method

Current LLM Provider uses the provider configured in LLM Settings. Shengsuan Cloud creates paid candidate batches and requires a quote confirmation.

Advanced Script Settings

Paragraph count controls script length. Custom requirements add style constraints. The system prompt defines the generation contract; restore the default unless you intentionally maintain your own prompt.

Providers and API keys

Keys belong to the service they unlock. Configure them once in Settings; tasks reuse the saved configuration.

OpenAI + fal.ai example:
llm_provider = "openai"
openai_api_key = "your-openai-api-key"
openai_model_name = "gpt-5.5"
openai_base_url = "https://api.openai.com/v1"

fal_api_key = "your-fal-api-key"
video_source = "fal"

Keep real credentials in your local config.toml; never commit it. fal.ai also accepts FAL_KEY as an environment variable.

Use the provider status message in Settings before testing. “Configuration ready” means the key, model, and endpoint are present; “Test Model Connection” verifies the actual request.

Audio Settings

Voiceover Mode

Auto generates narration from the script. Upload uses your audio file. None produces a video without narration.

Voice, volume, and speed

Voice selects the speaker; volume scales it; speed changes automatic narration timing. The narration duration controls how much visual material is required.

Background music

Choose random built-in music, a local file, or a configured generation provider. Keep background volume low enough that speech remains clear.

Custom audio

Uploaded narration replaces TTS while still allowing subtitles to be generated from the script.

Subtitle Settings

Subtitles are generated from the script and aligned to the narration. Use readable contrast and avoid placing text over important faces or UI.

Enabled and position

Enable subtitles and choose top, center, bottom, two-thirds bottom, or a custom position.

Display and animation

Sentence/word display and animation affect how captions appear, not the spoken content.

Font, size, color, stroke

Use a font installed in the runtime. White text with a dark stroke is a reliable cross-footage default.

Background

A solid or rounded background improves accessibility on busy footage; use it when the source visuals have high contrast variation.

Rendering and reliability

FFmpeg

Required for audio, subtitles, concatenation, and final encoding. If hardware encoding is unavailable, the app falls back to libx264.

Thread count

Controls render parallelism. Start with the default; increase only when CPU, memory, and thermal headroom are known.

Provider status

Check key presence first, then use the provider connection test. A valid-looking key can still fail because of an invalid model, endpoint, quota, network, or account permissions.

Paid providers

fal.ai, WaveSpeed, OFox, MiniMax, and batch services can create billable jobs. Review the estimate and confirmation control before starting.

Recommended first run

  1. Configure OpenAI in LLM Settings; confirm the status says ready and test the connection.
  2. Configure fal.ai in Material API; confirm its key status is ready.
  3. Enter a specific subject and let the LLM generate the script and keywords.
  4. Choose portrait 9:16, 5-second clips, 1 video, 1.0× speed, and subtitles enabled.
  5. Select fal.ai, review the paid clip estimate, confirm the charge, and generate.
  6. If the run fails, read the provider-specific error before changing unrelated settings.
